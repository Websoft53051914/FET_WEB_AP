## 系統概述

FTT 門市報修管理系統是專為門市人員設計的報修流程管理平台，提供從報修申請到結案的完整作業功能。

### 主要功能
- 🔧 報修單建立與管理
- 📋 審單流程處理  
- 👷 派工作業管理
- 💰 報價審核確認
- ✅ 完修結案處理
- 🔍 各式查詢報表

### 系統需求
- **瀏覽器**: Chrome 80+、Edge 80+、Firefox 75+
- **解析度**: 1024x768 以上
- **網路**: 穩定的網際網路連線

## 登入系統

### 1. 存取系統
1. 開啟瀏覽器，輸入系統網址
2. 系統會自動跳轉到登入頁面

### 2. 登入步驟
1. 輸入**使用者名稱**和**密碼**
2. 點擊「**登入**」按鈕
3. 系統驗證成功後，進入主畫面

### 3. 忘記密碼
1. 點擊「忘記密碼」連結
2. 輸入註冊的電子信箱
3. 系統會發送重設密碼的連結到您的信箱
4. 點擊信箱中的連結，設定新密碼

### 4. 首次登入
- 首次登入需要修改預設密碼
- 密碼需包含英文大小寫、數字，至少 8 位數
- 建議定期更換密碼以確保安全性

## 報修管理

### 新增報修單

#### 1. 進入報修單建立頁面
1. 點擊主選單「**報修管理**」→「**新增報修單**」
2. 系統顯示報修單建立表單

#### 2. 填寫基本資料
```
📍 門市資訊
- 門市代碼: [自動帶入當前門市]
- 門市名稱: [自動顯示]
- 聯絡人: [必填]
- 聯絡電話: [必填]

🔧 報修資訊  
- 報修類型: [下拉選擇]
- 緊急程度: [一般/緊急/非常緊急]
- 故障描述: [詳細描述故障情況]
- 希望完成日期: [選擇日期]
```

#### 3. 選擇維修項目
1. 點擊「**新增維修項目**」
2. 在樹狀結構中選擇維修項目
   - 📂 大分類 → 📂 中分類 → 🔧 維修項目
3. 輸入數量和說明
4. 可新增多個維修項目

#### 4. 上傳附件
- 支援格式：JPG, PNG, PDF, DOCX
- 單檔大小限制：10MB
- 總上傳容量：100MB
- 建議上傳故障現場照片

#### 5. 儲存報修單
1. 檢查資料完整性
2. 點擊「**儲存**」按鈕
3. 系統產生報修單號碼
4. 報修單狀態為「**新建**」

### 修改報修單

#### 可修改狀態
- ✅ **新建 (NEW)**: 可完全修改
- ✅ **退回修正 (REVISE)**: 可修改指定欄位
- ❌ **審核中**: 不可修改
- ❌ **已派工**: 不可修改

#### 修改步驟
1. 進入「**報修管理**」→「**報修單查詢**」
2. 搜尋要修改的報修單
3. 點擊「**修改**」按鈕
4. 修改相關資訊後，點擊「**更新**」

### 取消報修單

#### 可取消條件
- 狀態為「新建」或「退回修正」
- 尚未進入審核流程

#### 取消步驟
1. 找到要取消的報修單
2. 點擊「**取消**」按鈕
3. 填寫取消原因
4. 確認取消操作

## 審單作業

### 審核待辦清單

#### 1. 查看待審單
1. 點擊主選單「**審單作業**」
2. 系統顯示待審核的報修單清單
3. 清單資訊包括：
   - 📋 報修單號
   - 🏪 門市名稱
   - 🔧 報修類型
   - 📅 申請日期
   - ⚡ 緊急程度

#### 2. 審核優先順序
```
🚨 緊急程度排序:
1. 非常緊急 (紅色標示)
2. 緊急 (黃色標示)  
3. 一般 (綠色標示)

⏰ 時間排序:
- 系統自動依申請時間排序
- 超過 24 小時未審核會特別標示
```

### 審核作業

#### 1. 開始審核
1. 點擊報修單號碼進入詳細頁面
2. 仔細查看報修內容：
   - 🏪 門市基本資料
   - 🔧 故障描述與維修項目
   - 📎 相關附件
   - 📊 歷史維修記錄

#### 2. 審核決策
```
✅ 同意審核 → 狀態變更為「統一派工」
📝 退回修正 → 狀態變更為「退回修正」  
❌ 審核拒絕 → 狀態變更為「審核拒絕」
🔄 自行尋商 → 狀態變更為「同意自行尋商」
```

#### 3. 填寫審核意見
- **同意審核**: 可填寫注意事項
- **退回修正**: 必須說明需修正的項目
- **審核拒絕**: 必須說明拒絕理由
- **自行尋商**: 填寫相關建議

#### 4. 完成審核
1. 選擇審核結果
2. 填寫審核意見
3. 點擊「**送出審核**」
4. 系統自動通知相關人員

## 派工管理

### 系統自動派工

#### 1. 派工規則
```
🎯 派工優先條件:
- 服務區域符合
- 專業技能匹配  
- 廠商評等高
- 目前工作量較少
```

#### 2. 查看派工結果
1. 進入「**派工管理**」→「**派工查詢**」
2. 查看自動派工的結果
3. 可以看到指派的廠商資訊

### 手動派工

#### 1. 選擇廠商
1. 點擊「**重新派工**」
2. 系統顯示可用廠商清單
3. 廠商資訊包括：
   - 🏢 廠商名稱
   - ⭐ 評等分數
   - 📍 服務區域
   - 📞 聯絡方式
   - 💼 目前工作量

#### 2. 確認派工
1. 選擇適合的廠商
2. 設定期望完成日期
3. 填寫派工說明
4. 點擊「**確認派工**」

### 廠商回應處理

#### 1. 接受派工
- 廠商接受後，狀態變更為「**已派工**」
- 系統發送確認通知給門市

#### 2. 拒絕派工
- 需重新選擇其他廠商
- 可查看拒絕原因
- 系統建議替代廠商

## 報價確認

### 報價審核流程

#### 1. 收到報價通知
- 📧 系統會發送 Email 通知
- 🔔 系統內會有待辦提醒
- 📱 可設定手機簡訊通知

#### 2. 查看報價內容
1. 進入「**報價管理**」→「**報價審核**」
2. 點擊報修單號查看詳細報價
3. 報價內容包括：
   ```
   💰 費用明細:
   - 人工費用
   - 材料費用  
   - 其他費用
   - 總計金額
   
   📋 工作內容:
   - 維修項目明細
   - 預估工時
   - 使用材料清單
   ```

#### 3. 報價審核決策
```
✅ 同意報價:
- 金額 < 5萬: 直接同意
- 金額 ≥ 5萬: 需主管審核

❌ 拒絕報價:
- 需填寫拒絕原因
- 可要求重新報價
- 可重新派工給其他廠商
```

#### 4. 主管審核 (高額報價)
- 金額超過 5 萬元需主管審核
- 主管可以：
  - ✅ 同意報價
  - ❌ 拒絕報價  
  - 🔄 要求重新報價

## 完修結案

### 完修確認

#### 1. 廠商完修通知
- 廠商完工後會在系統中標記「完修」
- 門市會收到完修通知
- 需要門市最終確認才能結案

#### 2. 現場驗收
建議進行現場驗收：
- ✅ 檢查維修項目是否完成
- ✅ 測試設備功能是否正常
- ✅ 確認現場環境整潔
- ✅ 核對維修項目與報價內容

#### 3. 完修確認操作
1. 進入「**完修管理**」→「**完修確認**」
2. 查看維修完成的報修單
3. 點擊「**確認完修**」
4. 填寫驗收意見：
   ```
   😊 滿意: 維修品質良好
   😐 普通: 維修完成但有小瑕疵  
   😞 不滿意: 需要重新處理
   ```

### 結案處理

#### 1. 滿意結案
- 狀態變更為「**結案**」
- 系統記錄完修時間
- 可以對廠商進行評價

#### 2. 不滿意處理
- 可要求廠商重新處理
- 重新驗收完修結果
- 必要時可重新派工

#### 3. 廠商評價
完修結案後可對廠商評價：
- ⭐⭐⭐⭐⭐ 服務品質 (1-5星)
- ⭐⭐⭐⭐⭐ 技術能力 (1-5星)  
- ⭐⭐⭐⭐⭐ 服務態度 (1-5星)
- 📝 具體評價內容

## 常見問題

### Q1: 忘記密碼怎麼辦？
**A**: 點擊登入頁面的「忘記密碼」，輸入註冊信箱，系統會發送重設連結。

### Q2: 報修單建立後可以修改嗎？
**A**: 
- ✅ 新建狀態：可以完全修改
- ✅ 退回修正：可修改指定項目
- ❌ 其他狀態：不可修改

### Q3: 如何加速審核流程？
**A**: 
1. 詳細填寫故障描述
2. 上傳清楚的現場照片
3. 正確選擇維修項目
4. 標示適當的緊急程度

### Q4: 廠商拒絕派工怎麼處理？
**A**: 系統會自動建議其他可用廠商，或可手動選擇重新派工。

### Q5: 報價太高可以拒絕嗎？
**A**: 可以拒絕報價並要求重新報價，或選擇其他廠商重新派工。

### Q6: 系統運作緩慢怎麼辦？
**A**: 
1. 檢查網路連線狀況
2. 清除瀏覽器快取
3. 嘗試重新整理頁面
4. 聯絡系統管理員

### Q7: 如何查看歷史維修記錄？
**A**: 在報修單詳細頁面中，點擊「歷史記錄」頁籤可查看該門市的維修歷史。

### Q8: 可以同時處理多張報修單嗎？
**A**: 可以，系統支援多頁籤操作，可同時開啟多張報修單進行處理。

### Q9: 上傳的照片有什麼要求？
**A**: 
- 格式：JPG, PNG
- 大小：每檔不超過 10MB
- 建議：清晰的故障現場照片，有助於廠商了解問題

### Q10: 系統會自動儲存資料嗎？
**A**: 系統不會自動儲存，請記得在填寫完成後點擊「儲存」按鈕。

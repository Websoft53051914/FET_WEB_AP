## 系統概述

FTT 廠商系統是專為合作廠商設計的工作管理平台，協助廠商有效管理派工、報價、施工等各項作業流程。

### 主要功能
- 📬 接收派工通知
- 🤝 線上接案/拒絕
- 📋 現場作業回報
- 💰 線上報價作業
- ✅ 完修狀態回報
- 📊 工作績效查詢

### 系統需求
- **瀏覽器**: Chrome 80+、Edge 80+、Firefox 75+
- **行動裝置**: iOS 12+、Android 8+
- **網路**: 穩定的行動網路或 Wi-Fi

### 1. 存取系統

## 派工通知

### 接收通知方式

#### 1. 系統通知
- 🔔 登入系統後可查看待辦事項
- 📊 主畫面顯示新派工數量
- ⏰ 實時更新派工狀態

#### 2. Email 通知
- 📧 新派工會自動發送 Email
- 📋 信件包含報修單基本資訊
- 🔗 可直接點擊連結進入系統

#### 3. 簡訊通知 (選用)
- 📱 緊急派工會發送簡訊
- ⚡ 適用於非常緊急的案件
- 🔧 需在系統中設定手機號碼

### 派工資訊內容

#### 1. 基本資訊
```
📋 案件資訊:
- 報修單號: FTT20260112001
- 門市名稱: FET 信義門市
- 門市地址: 台北市信義區xxx路xxx號
- 聯絡人: 王店長
- 聯絡電話: 02-1234-5678

⏰ 時間要求:
- 希望到場時間: 2026/01/13 14:00
- 預計完成時間: 2026/01/15 18:00
- 緊急程度: 一般/緊急/非常緊急
```

#### 2. 故障描述
```
🔧 故障內容:
- 設備類型: 冷氣機
- 故障現象: 不冷、異音
- 詳細描述: 冷氣運轉正常但不冷，壓縮機有異音...
- 故障位置: 1樓營業區左側
```

#### 3. 維修項目
- 📝 具體維修項目清單
- 🔢 預估數量
- 💰 預算參考金額 (如有)
- 📎 相關附件 (現場照片等)

## 接案管理

### 查看新派工

#### 1. 進入派工清單
1. 點擊主選單「**派工管理**」
2. 系統顯示所有派工清單
3. 新派工會以特殊顏色標示

#### 2. 派工狀態說明
```
🆕 新派工 (藍色): 剛收到的派工，需要回應
⏳ 待回應 (黃色): 即將超時未回應
✅ 已接受 (綠色): 已接受的派工  
❌ 已拒絕 (紅色): 已拒絕的派工
⚠️ 超時 (灰色): 超過回應時間，自動拒絕
```

### 接受派工

#### 1. 查看派工詳情
1. 點擊報修單號查看詳細資訊
2. 仔細閱讀故障描述和維修要求
3. 查看現場照片 (如有)
4. 確認服務地點和時間

#### 2. 評估接案可行性
```
✅ 評估要點:
- 技能匹配度: 是否具備相關維修技能
- 時間可行性: 是否能在要求時間內完成
- 地點便利性: 服務地點是否在服務範圍內
- 工作量: 目前手上工作是否允許接案
```

#### 3. 接受派工操作
1. 點擊「**接受派工**」按鈕
2. 填寫預計到場時間
3. 填寫預計完成時間
4. 可填寫接案備註
5. 點擊「**確認接受**」

### 拒絕派工

#### 1. 拒絕原因
常見拒絕原因：
```
❌ 拒絕原因選項:
- 技能不符: 不具備相關維修技能
- 時間衝突: 無法在要求時間內處理
- 地點太遠: 超出服務範圍
- 工作飽和: 目前案件過多
- 設備缺乏: 缺乏必要工具或設備
- 其他原因: 請詳細說明
```

#### 2. 拒絕操作
1. 點擊「**拒絕派工**」按鈕
2. 選擇拒絕原因
3. 填寫詳細說明 (建議填寫)
4. 點擊「**確認拒絕**」

#### 3. 拒絕後續
- 系統會記錄拒絕原因
- 影響廠商評等和未來派工優先順序
- 建議合理拒絕，避免影響合作關係

## 現場作業

### 到場簽到

#### 1. 行動簽到
```
📱 使用手機操作:
1. 到達現場後開啟系統
2. 進入該案件詳細頁面
3. 點擊「現場簽到」
4. 系統自動記錄GPS定位
5. 上傳現場照片 (選用)
```

#### 2. 簽到資訊
- ⏰ 自動記錄到場時間
- 📍 GPS 定位確認位置
- 📷 可上傳現場狀況照片
- 📝 填寫初步檢查結果

### 現場狀況回報

#### 1. 初步檢查
到場後進行初步檢查：
- 🔍 確認故障現象
- 📋 檢查維修項目
- 🛠️ 評估所需工具材料
- ⏰ 預估維修時間

#### 2. 狀況回報
```
📱 回報內容:
- 實際故障情況
- 維修難度評估
- 所需材料清單
- 預估完成時間
- 現場照片上傳
```

#### 3. 特殊狀況處理
```
⚠️ 特殊狀況:
- 現場無人: 聯絡門市確認時間
- 故障描述不符: 回報實際狀況  
- 需要特殊材料: 申請採購或待料
- 超出維修範圍: 建議重新派工
```

### 作業進度更新

#### 1. 施工進度
定期更新作業進度：
- 🚀 開始施工
- 🔧 維修進行中  
- ⏸️ 暫停 (等料/其他原因)
- 🔄 恢復施工
- ✅ 施工完成

#### 2. 進度說明
每次更新進度時可填寫：
- 📝 目前作業內容
- 🚧 遇到的問題
- 📅 預計完成時間
- 📷 施工過程照片

## 報價作業

### 何時需要報價

#### 1. 需報價情況
```
💰 需要報價的情況:
- 維修費用超過一定金額
- 需要更換昂貴零件  
- 追加維修項目
- 門市要求提供報價
```

#### 2. 報價時機
- 🔍 初步檢查後，確定維修範圍
- 📋 列出所需材料和工時
- 💰 計算總費用後
- ⏰ 開始施工前

### 製作報價單

#### 1. 報價項目
```
📋 報價明細:
├── 🔧 人工費用
│   ├── 檢查診斷費
│   ├── 維修工時費  
│   └── 其他服務費
├── 🛠️ 材料費用
│   ├── 零件費用
│   ├── 耗材費用
│   └── 運輸費用
└── 💼 其他費用
    ├── 高空作業費
    ├── 緊急加班費
    └── 特殊工具費
```

#### 2. 報價製作步驟
1. 進入該案件的「**報價作業**」
2. 點擊「**新增報價項目**」
3. 填寫項目資訊：
   ```
   📝 項目資訊:
   - 項目名稱: 更換冷氣壓縮機
   - 規格型號: XXX-123-456
   - 數量: 1
   - 單價: 8,000
   - 小計: 8,000
   - 備註: 原廠零件，含安裝
   ```
4. 重複新增所有項目
5. 系統自動計算總金額

#### 3. 報價說明
```
📄 建議包含說明:
- 維修範圍和內容
- 使用材料規格  
- 施工方式說明
- 保固期間
- 付款方式
- 有效期限
```

### 送出報價

#### 1. 報價檢查
送出前請檢查：
- ✅ 項目內容完整正確
- ✅ 金額計算無誤
- ✅ 說明文字清楚
- ✅ 聯絡資訊正確

#### 2. 送出報價
1. 點擊「**預覽報價單**」
2. 確認報價內容無誤
3. 點擊「**送出報價**」
4. 系統自動通知門市

#### 3. 報價狀態
```
📊 報價狀態:
🟡 待審核: 門市尚未回覆
🟢 已同意: 可以開始施工
🔴 已拒絕: 需要重新報價或討論
⏳ 已過期: 超過有效期限
```

## 完修回報

### 完工檢查

#### 1. 自我檢查清單
完工前進行最後檢查：
```
✅ 檢查項目:
- 維修項目是否完全完成
- 設備功能是否正常運作
- 有無遺漏的維修內容
- 現場環境是否整潔
- 工具材料是否收拾完畢
```

#### 2. 測試驗證
- 🔧 功能測試：確保設備正常運作
- 🔍 外觀檢查：確保外觀完整無損
- 📊 性能測試：檢查性能是否達標
- 🧹 清潔整理：清理現場環境

### 完修回報操作

#### 1. 回報完修
1. 進入該案件詳細頁面
2. 點擊「**完修回報**」
3. 填寫完修資訊：
   ```
   📝 完修資訊:
   - 實際完成時間
   - 維修內容摘要
   - 使用材料清單
   - 測試結果說明
   - 注意事項
   ```

#### 2. 上傳完修照片
- 📷 維修前後對比照片
- 🔧 維修過程重要步驟
- ✅ 完工後設備狀態
- 🧹 現場整潔狀況

#### 3. 填寫維修報告
```
📋 維修報告內容:
- 故障原因分析
- 維修方法說明  
- 更換零件清單
- 預防措施建議
- 保固說明
```

### 門市確認

#### 1. 等待門市驗收
- 完修回報後等待門市確認
- 門市會進行現場驗收
- 可能需要配合說明維修內容

#### 2. 驗收結果
```
📊 可能的驗收結果:
✅ 驗收通過: 案件結案，等待付款
🔄 需要調整: 根據意見進行微調
❌ 驗收不通過: 需要重新處理
```

#### 3. 後續處理
- ✅ 通過：案件完成，更新績效記錄
- 🔄 調整：配合調整，重新驗收
- ❌ 不通過：了解問題，重新處理

## 常見問題

### Q1: 收到派工通知後多久需要回應？
**A**: 一般案件需在 2 小時內回應，緊急案件需在 30 分鐘內回應。

### Q2: 可以同時接受多個派工嗎？
**A**: 可以，但請確保能在承諾時間內完成所有工作。

### Q3: 拒絕派工會影響廠商評等嗎？
**A**: 合理的拒絕不會影響評等，但頻繁無故拒絕會降低評等和派工優先順序。

### Q4: 現場發現故障與描述不符怎麼辦？
**A**: 立即在系統中回報實際狀況，並聯絡門市確認處理方式。

### Q5: 需要採購特殊材料時如何處理？
**A**: 在系統中標記「待料」狀態，並說明所需材料和預計到貨時間。

### Q6: 報價被拒絕後可以重新報價嗎？
**A**: 可以，了解拒絕原因後調整報價內容重新提交。

### Q7: 完修後發現問題如何處理？
**A**: 在保固期內的問題需免費重新處理，請主動聯絡門市安排時間。

### Q8: 如何提高接案優先順序？
**A**: 
1. 維持良好的接案率
2. 準時完工
3. 提供優質服務
4. 獲得高評價

### Q9: 緊急派工的加班費如何計算？
**A**: 依契約規定計算，通常為正常工時費的 1.5-2 倍。

### Q10: 系統操作遇到問題如何求助？
**A**: 可以撥打技術支援電話或使用系統內的線上客服功能。
